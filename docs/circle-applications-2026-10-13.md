# فرم پذیرش حلقه

رزومه PDF یا DOCX تا ۸ مگابایت، مقطع، دانشگاه، رشته/گرایش، سابقه بالینی، رویکرد و حوزه فعالیت الزامی هستند. شماره نظام/دانشجویی و توضیحات اختیاری‌اند؛ دانشجویان می‌توانند سابقه را «بدون سابقه» و رویکرد را «در حال آموزش» ثبت کنند.

اطلاعات همراه درخواست با وضعیت requested در دیتابیس ثبت می‌شود؛ تکمیل فرم تأیید پذیرش یا پرداخت نیست. فایل در storage خصوصی ذخیره می‌شود و فقط مدیر دارای engagements.view از پنل درخواست‌های حلقه آن را دانلود می‌کند.

برای ارتقا فایل database/cpanel/circle_applications_upgrade_2026_10_13.mysql.sql را Import کنید. فایل کامل latest_schema_2026_10_13.mysql.sql اکنون ۴۴ جدول دارد. اجرا تکراری جدول یا داده اولیه تکراری ایجاد نمی‌کند. کاربران و درخواست‌های قبلی حفظ می‌شوند؛ درخواست‌های قدیمی به‌صورت مصنوعی دارای رزومه نمی‌شوند.

Cron سازگار با هاست‌هایی که فقط فایل PHP می‌پذیرند:

```
/usr/local/bin/php /home/h419512/public_html/bin/communications-cron.php
```

زمان: هر دقیقه. توکن از .env خصوصی خوانده می‌شود؛ وب‌هوک یک بار تنظیم می‌شود و سپس صف مشترک پردازش می‌شود. وضعیت بدون اسرار در storage/data/communications-cron-status.json قرار دارد.
